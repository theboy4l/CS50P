# CS50P — My Python Journey

This repository collects my solutions and projects from Harvard's CS50's Introduction to Programming with Python (CS50P).

## Course work

- Week 0 — Functions: Faces, Einstein, Indoor Voice, Playback Speed, Tip Calculator
- Week 1 — Conditionals: Bank, Deep Thought, File Extensions, Math Interpreter, Meal Time
- Week 2 — Loops: Camel Case, Coke Machine, Nutrition Facts, Vanity Plates, Twttr
- Week 3 — Exceptions: Fuel Gauge, Grocery List, Taqueria
- Week 4 — Libraries: Adieu, Bitcoin Price, Emoji, Figlet, Guessing Game, Little Professor
- Week 5 — Unit Tests: Tests are kept beside the exercises they cover
- Week 6 — File I/O: Lines of Code, Pizza, Scourgify, Shirt, Shirtificate
- Week 7 — Regular Expressions: Numb3rs, Response, Um
- Week 8 — Object-Oriented Programming: Jar, Seasons of Love

The folders contain the exercises I shared for this portfolio. Some exercises need image files or sample input files supplied separately by the course.

## Final project

My final project is Student Life Manager, a command-line application for tasks, timetables, budgeting, study sessions, and GPA calculations. See the Final Project folder for its source and project description.

## Dependencies

The root requirements file lists packages used by exercises across the repository. Install them with:

    python -m pip install -r requirements.txt

Each exercise is a separate program. Some require command-line arguments, input files, or assets to run.
